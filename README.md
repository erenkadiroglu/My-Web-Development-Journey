# 🚀 My Web Development Journey - HTML

### 🇹🇷 Proje Hakkında (Turkish)
Bu depo, web geliştirme yolculuğumun **HTML** aşamasında öğrendiğim temel kavramları, etiketleri ve yapıları içeren bir koleksiyondur. Her klasör belirli bir konuya odaklanmaktadır.

### 📂 Klasör Yapısı
- **01-Basic-Structure:** HTML sayfasının temel iskeleti (Boilerplate).
- **02-Text-Formatting:** Başlıklar, paragraflar ve metin düzenleme.
- **03-Hyperlinks:** Sayfalar arası geçiş ve bağlantı oluşturma.
- **04-Images:** Web sayfasına görsel ekleme ve yönetimi.
- **05-Audios:** Ses dosyalarını oynatma ve kontrol etme.
- **06-Videos:** Video içerikleri ve video oynatıcı kullanımı.
- **Assets:** Projelerde kullanılan resim, ses ve video kaynakları.

### 🇺🇸 About The Project (English)
This repository is a collection of fundamental concepts, tags, and structures I learned during the **HTML** stage of my web development journey. Each folder focuses on a specific topic.

### 📂 Folder Structure
- **01-Basic-Structure:** Core HTML boilerplate and structure.
- **02-Text-Formatting:** Headings, paragraphs, and text styling.
- **03-Hyperlinks:** Internal/external links and navigation.
- **04-Images:** Adding and managing images on the web.
- **05-Audios:** Integrating and controlling audio files.
- **06-Videos:** Embedding video content and player controls.
- **Assets:** Shared media files (images, audio, video) used in projects.
