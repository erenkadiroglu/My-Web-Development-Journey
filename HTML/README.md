## 🇺🇸 English Description
This folder contains all technical studies and application examples from my HTML learning process. The fundamental components forming the skeleton of web pages are documented in a modular structure.

### 📊 Folder Contents and Details

| Folder Name | Topic | Technical Content |
| :--- | :--- | :--- |
| **[01-Basic-Structure](./01-Basic-Structure)** | Basic Structure | HTML5 standards, boilerplate structure, and page hierarchy. |
| **[02-Text-Formatting](./02-Text-Formatting)** | Text Formatting | Headings, paragraphs, semantic text tags, and lists. |
| **[03-Hyperlinks](./03-Hyperlinks)** | Hyperlinks | Navigation menus, internal and external link management. |
| **[04-Images](./04-Images)** | Image Management | Web optimization, accessibility, and image paths. |
| **[05-Audios](./05-Audios)** | Audio Files | Audio file integration and browser controls. |
| **[06-Videos](./06-Videos)** | Video Files | Video embedding techniques and source management. |
| **[07-Favicons](./07-Favicons)** | Favicon Usage | Browser tab icons and defining icons with the link tag. |
| **[08-Text-Styles](./08-Text-Styles)** | Text Styles | Bold, italic, underlined/strikethrough text, and HTML text formatting tags. |
| **[Assets](./Assets)** | Asset Files | Common media library used throughout the projects. |

### 🚀 How to Run?
You can view the works by opening the `index.html` file inside any folder in your browser.
